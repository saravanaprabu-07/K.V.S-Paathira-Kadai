# K.V.S Paathira Kadai — Utensil & Event Equipment Rentals

A sleek, responsive portfolio web application designed for a local rental business. The platform showcases high-quality catering utensils, cooking vessels, and event infrastructure management equipment tailored for weddings, family functions, and community celebrations.

## 🌐 Live Demo
* **Local Preview:** Open `index.html` directly in any modern web browser.
* **Business Location:** Seydunganallur, Thoothukudi District, Tamil Nadu, India.

---

## ✨ Features
* **Premium Hero Section:** High-impact landing zone with a dynamic, elegant color scheme built for local businesses.
* **Interactive Navigation:** Smooth structural scrolling map to navigate between Home, About, Our Rentals, Event Equipment, and Contacts.
* **Instant Conversions:** Integrated hot-links for **Enquire Now** and direct click-to-chat **WhatsApp Enquiry** to drive business leads effortlessly.
* **Localized Context:** Persistent footer anchoring with physical business address credentials and phone links.

---

## 🛠️ Tech Stack
* **Frontend:** Semantic HTML5, Modern CSS3 Layouts (Flexbox/Grid).
* **Typography:** Elegant Editorial Serif paired with clean sans-serif accents for optimal scannability.
* **Assets:** Custom iconography, vector brand marks, and high-performance background styling gradients.

## 🚀 Getting Started

### Prerequisites
To review or host this repository locally, you only need an internet browser.

### Installation
1. Clone this repository to your local computer system:
   ```bash
   git clone https://github.com
   ```
2. Navigate directly into the root folder directory:
   ```bash
   cd P.A.G.E-PROJECT
   ```
3. Launch the platform interface:
   * Double-click `index.html` to open it in your browser.
   * *Alternatively*, if using VS Code, right-click `index.html` and select **Open with Live Server**.
